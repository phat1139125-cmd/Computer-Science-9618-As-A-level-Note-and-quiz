THEORY — ETHICS & OWNERSHIP
TOPIC 01 · §7.1
Professional Ethics
BCS · IEEE · ACTING ETHICALLY · CLIENT INTERESTS
WHY JOIN AN ETHICAL BODY (BCS/IEEE)
  • Has set ethical guidelines — no decision-making required by individual
  • Professional integrity — clients/staff know you are reputable
  • Provides help, support and legal advice
  • Training courses — keeps skills up to date
Why Act Ethically
  • Make team members feel valued
  • Maximise quality of work
  • Promote teamwork and cooperation
  • Enable creation of best product for customer
Acting in Best Interest of Client
  • Keep client's personal data private
  • Involve client in development / communicate regularly
  • Provide solutions the client asked for
  • Keep project on schedule and within budget
  • Inform client of any problems/delays
How to Act Ethically
  • Be truthful — ask for help when needed
  • Perform your own research
  • Ask for additional training/mentor
Being Unethical — Consequences
  • Product may fail if error not reported
  • Client: code may not work, lets down client
  • Profession: failing duties as employee
  • Company: reputational damage
TOPIC 02 · §7.1
Copyright & Software Licensing
COPYRIGHT · OPEN SOURCE · SHAREWARE · COMMERCIAL
COPYRIGHT

Formal and legal rights to ownership / Intellectual property rights. Protects against unauthorised reproduction. Allows legal right of redress.

Preventing Illegal Copies
Methods
  • Encryption
  • Product key / serial number
  • Compile source code — distribute as .exe file
LICENCE TYPECAN EDIT?CAN REDISTRIBUTE?COST?
Open Source✅ Yes — must release under same licence✅ YesUsually free
Shareware❌ No❌ NoFree trial, then paid
Commercial❌ No❌ NoMust pay before use
✅ Open Source Licence — For
  • Allows user to customise code
  • Errors can be reported by community
  • Additional features can be added
  • Allows collaboration
❌ Open Source Licence — Against
  • Must release source code
  • Anyone can edit/modify and share
  • Cannot profit from the program
Shareware Advantages
  • Free trial — more people experience product
  • Can gain income if bought after trial
  • User cannot redistribute — protects IP
  • More people likely to buy after trying
Commercial Software Advantages
  • Fee charged — programmer gains income
  • Source code protected
  • Cannot be redistributed or edited
  • Action can be taken against illegal copies
  • Fewer bugs, better support
TOPIC 03 · §7.1
Artificial Intelligence (AI)
APPLICATIONS · SOCIAL IMPACTS · ECONOMIC IMPACTS
AI Applications
  • Facial/image recognition — police identifying wanted people
  • Natural language interfaces — speech recognition
  • Self-driving cars — collision avoidance, route following
  • Game playing — characters react to player movements
  • Security cameras — detect/track movement
Social Impacts
  • Privacy issues — people don't like data being stored
  • Incorrect recognition leads to mistakes
  • Individuals feel safer — reduction in crime
  • Helps catch criminals
Economic Impacts
  • Reduces costs — tasks carried out faster by AI
  • Increases profits — more efficient work
  • Decreases cost for customer
  • Can decrease profit margins — expensive to maintain/buy/update

QUESTION 03
Compare open source and commercial software licences. [4]

MARK SCHEME (any 4 contrasting pairs)

  • Open source: user can edit/modify source code / Commercial: user cannot edit source code (1)
  • Open source: user can redistribute / Commercial: cannot be redistributed (1)
  • Open source: usually free / Commercial: user must pay (1)
  • Open source: source code publicly available / Commercial: source code protected (1)

★ CHALLENGE
QUESTION 05
A software developer is asked to use an open source library in a commercial project.
Explain two reasons why the developer might choose NOT to use an open source licence for their own project. [4]

MARK SCHEME

  • Must release source code publicly (1) — competitors could access and copy the code (1)
  • Cannot profit directly from the open source project (1) — commercial software allows charging a fee (1)
  • Anyone can edit/modify the code (1) — developer loses control over how the software is used or modified (1)

QUESTION 06
Explain two economic impacts of introducing AI into a business. [4]

MARK SCHEME (any 2 × 2)

  • Reduces costs (1) — redundant/repetitive tasks done by AI faster/cheaper than by humans (1)
  • Increases profits (1) — more efficient work performance increases output (1)
  • Can decrease profit margins (1) — AI systems are expensive to purchase, maintain and update (1)
