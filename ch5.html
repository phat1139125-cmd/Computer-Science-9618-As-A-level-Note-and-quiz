TOPIC 01 · §5.1
Operating System — Purpose & Management Tasks
PURPOSE · MEMORY · FILE · SECURITY · HARDWARE · PROCESS MANAGEMENT
PURPOSE OF AN OS
  • Provide a user interface
  • Provide a platform for software to run
  • Hide complexities of hardware from user
Memory Management
  • Controls movement of data between RAM/processor
  • Allocates memory to processes dynamically
  • RAM assigned into blocks
  • Prevents two programs occupying same RAM
  • Moves data from secondary storage when needed
  • Manages paging and virtual memory
File Management
  • Space allocated to particular files
  • Maintains a directory structure
  • Provides file naming abilities
  • Implements access rights
  • Allows file sharing
  • Specifies tasks on files (copy, paste, delete)
Security Management
  • Creates accounts and passwords
  • Provides firewall or anti-malware
  • Validates user and process authenticity
Hardware Management
  • Receives data from input devices
  • Sends data to output devices
  • Installs and operates device drivers
  • Allows communication between peripherals
  • Handles buffers for data transfer
  • Manages interrupts from devices
Process Management
  • Manages scheduling of processes
  • Manages resources processes require
  • Enables processes to share/transfer data
  • Prevents interference between processes
  • Handles process queue
  • Supports multitasking
Input/Output Management
  • Manages communication with I/O devices
  • Handles device drivers
  • Error checking and recovery
⚡ OS MANAGEMENT TASKS — MNEMONIC  MF·SH·PI = Memory, File, Security, Hardware, Process, I/O. Each = 1 mark in "state 4 OS management tasks" questions.
TOPIC 02 · §5.1
Utility Software
DISK FORMATTER · DEFRAG · DISK REPAIR · BACKUP · COMPRESSION · VIRUS CHECKER
PURPOSE

Utility software helps set up, optimise and maintain the computer. Makes memory allocation more efficient and checks the system for faults.

Disk Formatter
  • Prepares/initialises disk for storing files
  • Partitions disk, generates new file system
  • Can delete all data from disk
  • Sets up file allocation table
  • Checks disk for errors
Defragmentation
  • Files become fragmented over time (saving/deleting)
  • Moves/rearranges blocks so each file is contiguous
  • Moves free space together
  • Less head movement → faster access
  • Improves disk access times
Disk Repair
  • Scans for errors/inconsistencies in disk
  • Corrects errors — prevents bad sectors being used
  • Reduces access times by optimising storage
Backup Software
  • Creates copy of data at regular intervals
  • Allows retrieval if data is lost/corrupted
  • Provides security against data loss
Compression Software
  • Reduces file size
  • Saves storage and memory space
  • Reduces transmission time
Virus Checker
  • Scans for malicious program code
  • Checks against stored database of viruses
  • Database needs regular updates
  • Quarantines or deletes detected viruses
  • Checks downloaded files against database
TOPIC 03 · §5.1
Program Libraries & DLL
PROGRAM LIBRARY · DYNAMIC LINK LIBRARY · BENEFITS
PROGRAM LIBRARY

Contains pre-written functions and subroutines that can be referenced or imported. The functions/routines can be called in your own program.

Benefits of Program Libraries
  • Saves time — code not written from scratch
  • More likely to work correctly (already tested)
  • Program updates automatically if routine updated
  • Can perform complex calculations programmer cannot
Dynamic Link Library (DLL) Benefits ★
  • Requires less main memory — DLL loaded only once when needed
  • Executable file is smaller (not all library routines included)
  • No maintenance needed from programmer (DLL is separate)
  • No need to recompile program if DLL changes
  • Changes to DLL done independently of main program
⚡ DLL KEY BENEFIT  "DLL is only loaded into memory once when needed, so multiple programs can share it without each needing their own copy in memory." This saves RAM = key exam mark.
TOPIC 04 · §5.2
Compiler vs Interpreter
WHEN TO USE · ADVANTAGES · DISADVANTAGES ★
FEATURECOMPILERINTERPRETER
TranslationEntire code translated at once, then runLine by line — each line translated then executed
When usedAfter program is completedWhile writing/testing a program
Error reportingError report after full translationStops at first error — shows position immediately
OutputCreates executable file (.exe)No executable — must retranslate each run
SpeedFaster execution (pre-compiled)Slower (translates each run)
Source codeUsers cannot access/edit source codeSource code visible
✅ Compiler — After Testing
  • Produces executable — runs without source code
  • Source code protected from users
  • Can compile for different hardware
  • Program tested multiple times without retranslating
  • Debug multiple errors simultaneously
❌ Compiler — During Testing
  • Cannot change code without recompilation
  • Won't run if any errors exist
  • Errors not corrected in real-time
  • One error may cause false errors elsewhere
  • Cannot test incomplete/individual sections
✅ Interpreter — During Testing
  • Real-time changes visible immediately
  • Debuggable at each stage
  • Can test when incomplete
  • Errors corrected in real-time
  • Small parts tested individually
ASSEMBLER

Translates assembly language into machine code. Specific to one processor architecture.

⚡ EXAM PATTERN  "Justify use of interpreter during development": stops at first error → programmer can correct immediately. Can test incomplete program. No need to recompile after each change. "Justify compiler for distribution": executable file → users don't need translator. Source code protected.
TOPIC 05 · §5.2
IDE Features & Tools
CODING · ERROR DETECTION · PRESENTATION · DEBUGGING
Coding Tools
  • Context sensitive prompts — displays predictions/options as code is written
  • Auto-complete — suggests what to type next
  • Auto-correct
Error Detection
  • Dynamic syntax check — underlines/highlights syntax errors in real-time as code is entered
Presentation
  • Pretty printing — highlights key terms with colour
  • Auto-indentation
  • Expand/collapse code blocks
Debugging Tools ★
  • Single stepping — runs code one line at a time, showing effect of each statement
  • Breakpoints — stops code at a set line to check current values
  • Report windows — outputs contents of variables and data structures
⚡ IDE DEBUGGING ★  Single stepping, breakpoints and report windows are the three most exam-tested IDE tools. For each: name it + what it does + WHY it helps debug. "Breakpoints allow programmer to pause execution at a specific line to inspect variable values at that point."

QUESTION 04 · Compare
Compare the use of a compiler and an interpreter when testing a program during development. [4]

MARK SCHEME (any 4 contrasting pairs)

Examiner: Both sides for each mark. Context is "during development/testing" — focus on debugging advantages of interpreter.

QUESTION 05 · Explain
Explain two advantages of using a compiler rather than an interpreter once a program has been completed and is ready for distribution. [4]

MARK SCHEME (any 2 × 2)

  • Source code is not accessible to users (1) — prevents them from editing or copying the program (1)
  • Can be compiled for different hardware specifications (1) — allows distribution to wider range of users/devices (1)
  • Program executes faster (1) — no translation overhead at runtime (1)
