TOPIC 01 · §18.1
How Graphs Aid AI
PURPOSE OF GRAPHS · STRUCTURE · USE IN AI PROBLEMS
HOW GRAPHS AID AI
  • Artificial Neural Networks can be represented using graphs
  • Graphs provide structures for relationships between data
  • AI problems can be defined as finding a path in a graph
  • Graphs may be analysed by a range of algorithms (e.g. Dijkstra's, A*)
Graph Structure
  • Consists of nodes (vertices) and edges (connections)
  • Edges can be directed or undirected
  • Edges can be weighted (cost, distance, time)
  • Can be cyclic or acyclic
Graphs as ADTs in AI
  • Nodes represent states/positions
  • Edges represent possible transitions
  • Weights represent cost of transition
  • Path = sequence of decisions/moves
  • Goal = find optimal path between two nodes
⚡ EXAM NOTE  Candidates will NOT be required to write algorithms to set up, access or perform searches on graphs. You only need to know the purpose, structure and how they aid AI problems.
TOPIC 02 · §18.1
A* and Dijkstra's Algorithms
PURPOSE · HOW THEY WORK · WHEN USED
PURPOSE

To find the optimal shortest and most cost-effective route between two nodes in a graph, based on distance, cost or time.

Dijkstra's Algorithm
  • Finds shortest path from a source node to ALL other nodes
  • Works on graphs with non-negative weights
  • Explores all nodes — guarantees shortest path
  • Used in GPS, routing tables, network navigation
  • Does not account for a heuristic — explores more nodes
A* Algorithm
  • Finds shortest path from source to a SPECIFIC target node
  • Uses a heuristic (estimated cost to goal) to guide search
  • More efficient — explores fewer nodes than Dijkstra's
  • Used in game AI, robotics, pathfinding
  • f(n) = g(n) + h(n): actual cost + estimated cost to goal

TOPIC 03 · §18.1
Artificial Neural Networks (ANNs)
STRUCTURE · HOW THEY ENABLE MACHINE LEARNING · BACK PROPAGATION
ARTIFICIAL NEURAL NETWORK
  • Part of AI — simulates function of a human brain
  • Key component of machine learning
  • Has self-learning capabilities — improves as more data available
  • Can solve complex problems humans find difficult
Structure
  • Input layer: receives data
  • Hidden layers: extract characteristics, calculate outputs
  • Output layer: provides results/decisions
  • Weights assigned between nodes — adjusted through training
How ANNs Enable Machine Learning
  • Replicates how human brains work
  • Weights adjusted through training → more accurate results
  • Data input at input layer → analysed at each hidden layer
  • Characteristics extracted/outputs calculated at each layer
  • Reinforcement learning through repeated training
  • Decisions made without being specifically programmed
Multiple Hidden Layers
  • Enables deep learning
  • Needed for higher complexity problems
  • Network learns and makes decisions on its own
  • Improves accuracy — more layers = more complex learning
  • Creates complex feature detectors
Back Propagation of Errors
  • Used to correct errors in the network
  • Error calculated at output layer
  • Error propagated back through network
  • Weights adjusted to reduce error
  • Process repeated until accuracy acceptable
TOPIC 04 · §18.1
Deep Learning
DEFINITION · HOW IT WORKS · REASONS FOR USE
DEEP LEARNING
  • Simulates data processing abilities of human brain
  • Uses ANNs with many hidden layers — progressively extracts higher-level features
  • Specialised form of machine learning
  • Trained using large amounts of unlabelled data
Reasons for Using Deep Learning
  • Makes good use of unstructured data
  • Outperforms other ML methods when data size is large
  • Processes data with a non-linear approach
  • Effective at identifying hidden patterns too complex for humans
  • More accurate outcomes with more hidden layers
  • Enables machines to process data autonomously
⚡ DEEP LEARNING KEY POINT  Deep learning = many hidden layers + large unlabelled datasets. The "deep" refers to the depth (number of hidden layers). More layers = can detect more complex, abstract patterns.
TOPIC 05 · §18.1
Machine Learning
SUPERVISED · UNSUPERVISED · COMPARISON
Supervised Learning
  • Uses labelled input data — known input with associated output
  • Learns from sample data with known correct outputs
  • Able to predict future outcomes based on past data
  • e.g. spam detection, image classification
Unsupervised Learning
  • Uses unlabelled input data — no correct output given
  • Finds previously unknown patterns in data
  • Only requires input data
  • e.g. customer segmentation, anomaly detection

TOPIC 06 · §18.1
Reinforcement Learning
HOW IT WORKS · FEEDBACK · REASONS FOR USE
REINFORCEMENT LEARNING
  • Based on feedback — AI learns through actions and seeing results
  • Works through trial and error — learns from own experiences
  • Good action → positive feedback (reward)
  • Bad action → negative feedback (penalty)
  • Node weightings adjusted to achieve correct outcome
  • AI uses feedback to improve performance in similar tasks
Reasons for Using Reinforcement Learning
  • Enables autonomous learning using feedback without labelled data
  • System improves through experience — no human intervention needed
  • Effective for complex decision-making problems
  • e.g. game playing AI, robotics, self-driving cars
⚡ THREE LEARNING TYPES COMPARISON  Supervised = labelled data, known answers. Unsupervised = unlabelled, finds patterns. Reinforcement = no labelled data, learns from reward/penalty feedback. Deep learning can use any of these approaches with many hidden layers.
