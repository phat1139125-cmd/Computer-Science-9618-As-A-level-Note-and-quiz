TOPIC 01 · §10.1
Data Types & Records
PRIMITIVE TYPES · RECORD STRUCTURE · BOOLEAN USES
Primitive Data Types
  • INTEGER — whole numbers
  • REAL — decimal numbers
  • CHAR — single character
  • STRING — sequence of characters
  • BOOLEAN — TRUE or FALSE
  • DATE — date value
Uses of BOOLEAN
  • To terminate a conditional loop when value has been found
  • When variable can only take one of two possible values
  • As a flag variable
Record Definition — Pseudocode
// Define a record type TYPE Student DECLARE StudentID : INTEGER DECLARE StudentName : STRING DECLARE Grade : CHAR ENDTYPE // Declare array of records DECLARE Students : ARRAY[1:30] OF Student // Access record fields Students[1].StudentName ← "Ahmed" OUTPUT Students[1].Grade
Advantages of Records
  • Set of data of different data types stored under single identifier
  • Multiple instances referenced using one identifier
  • Logical grouping of related data
TOPIC 02 · §10.2
Arrays
1D ARRAYS · 2D ARRAYS · ADVANTAGES
// 1D Array declaration DECLARE Scores : ARRAY[1:10] OF INTEGER // 2D Array declaration DECLARE Grid : ARRAY[1:5, 1:5] OF INTEGER // Accessing elements Scores[3] ← 85 Grid[2,4] ← 99 // Iterating through array FOR i ← 1 TO 10 OUTPUT Scores[i] NEXT i
Array Advantages
  • Simplify algorithm — easier to amend or add data
  • Easier to understand, test and debug
  • Can iterate through values using a loop
  • Arrays of records can store multiple data types
TOPIC 03 · §10.3
Files
READ · WRITE · WHY USE FILES
Advantages of Files
  • Data persists after computer switched off
  • Data not manually re-entered each run
  • Large amounts of data stored permanently
// Writing to a file — WRITE overwrites ALL existing data OPENFILE "data.txt" FOR WRITE WRITEFILE "data.txt", DataToWrite CLOSEFILE "data.txt" // Appending to a file — APPEND adds to end, preserves existing data OPENFILE "data.txt" FOR APPEND WRITEFILE "data.txt", NewData CLOSEFILE "data.txt" // Reading from a file OPENFILE "data.txt" FOR READ READFILE "data.txt", DataVariable CLOSEFILE "data.txt" // Reading all lines with EOF check OPENFILE "data.txt" FOR READ WHILE NOT EOF("data.txt") READFILE "data.txt", Line OUTPUT Line ENDWHILE CLOSEFILE "data.txt"
⚠️ FOR WRITE
  • Overwrites the ENTIRE file completely
  • All existing data is LOST
  • Use when creating a new file or replacing all content
✅ FOR APPEND
  • Adds new data to the END of the file
  • Existing data is PRESERVED
  • Use when adding records to an existing file
📖 FOR READ
  • Opens file to read data only
  • Use EOF() to check for end of file
  • Always CLOSEFILE after use
⚡ WRITE vs APPEND  WRITE = destroys existing data (start fresh). APPEND = preserves existing data (add to end). Exam question: "add new students to existing file" → use APPEND. "Create a new file" → use WRITE. File names always in quotes with .txt.
TOPIC 04 · §10.4
Linked Lists
STRUCTURE · ADDING/REMOVING NODES · ADVANTAGES
LINKED LIST

Consists of nodes — each node contains data and a pointer to the next node. Has a start pointer. Last node has a null pointer. Unused nodes stored on free list.

Structure
  • Start pointer — points to first node
  • Each node: data + pointer to next node
  • Null pointer — indicates end of list
  • Free list — stores unused/available nodes
✅ Advantages
  • Easier to add/delete data — only pointers changed
  • Dynamic size — can grow/shrink as needed
  • No shifting of data required
❌ Disadvantages
  • Pointers need to be stored as well as data
  • More complex to implement
  • Cannot access elements randomly (must traverse)
Adding a Node — Steps

Check for an empty node in free list

Assign data item to first empty node (call it X)

Set pointer of X to point to the node that will come after it (Y)

Set pointer of node that previously pointed to Y to point to X

Update free list pointer to next empty node

Implementation — Pseudocode
// Declare linked list using two parallel arrays DECLARE Data : ARRAY[0:9] OF STRING DECLARE Pointer : ARRAY[0:9] OF INTEGER DECLARE StartNode : INTEGER DECLARE FreeNode : INTEGER // Traverse linked list Current ← StartNode WHILE Current <> -1 // -1 = null pointer OUTPUT Data[Current] Current ← Pointer[Current] ENDWHILE
TOPIC 05 · §10.4
Queues
FIFO · ADDING · REMOVING · CIRCULAR QUEUE
QUEUE

Works on FIFO (First In, First Out) basis. Has Front and End (Tail) pointers. May be circular.

OPERATIONSTEPSCHECK FIRST
Add (Enqueue)Increment End pointer → store data at End pointer positionQueue is NOT full
Remove (Dequeue)Return value at Front pointer → increment Front pointerQueue is NOT empty
Circular Queue
  • Both Head and Tail pointers initialised to 0
  • If Tail reaches max, it wraps back to 0
  • If Head reaches max, it wraps back to 0
  • Tracks number of items in queue
Queue vs Stack
  • Queue: FIFO — data removed in ORDER received
  • Stack: LIFO/FILO — data removed in REVERSE order
  • Queue: two pointers (Front + End)
  • Stack: one pointer (Top)
TOPIC 06 · §10.4
Stacks
LIFO · PUSH · POP · USES
STACK

Works on LIFO/FILO (Last In, First Out) basis. Has one pointer — the Top Pointer. Push adds to top; Pop removes from top.

Stack Uses
  • Recursion — stores return addresses
  • Interrupt handling — saves register contents
  • Procedure calls — stores local variables
  • Evaluating RPN expressions
  • Implementing ADTs
// Stack implementation DECLARE Stack : ARRAY[0:9] OF STRING DECLARE TopPointer : INTEGER TopPointer ← -1 // empty stack // PUSH operation PROCEDURE Push(Item : STRING) IF TopPointer < 9 THEN TopPointer ← TopPointer + 1 Stack[TopPointer] ← Item ENDIF ENDPROCEDURE // POP operation FUNCTION Pop() RETURNS STRING IF TopPointer >= 0 THEN Item ← Stack[TopPointer] TopPointer ← TopPointer - 1 RETURN Item ENDIF ENDFUNCTION
⚡ STACK CHECKS  Always check if stack is FULL before PUSH (TopPointer = max). Always check if stack is EMPTY before POP (TopPointer = -1 or 0 depending on initialisation). These checks = exam marks.

QUESTION 01
Describe the difference between a queue and a stack. [4]

MARK SCHEME (any 4)

  • Queue: FIFO — first data item in is first removed / Stack: LIFO — last data item in is first removed (1)
  • Queue has two pointers (Front and End) / Stack has one pointer (Top) (1)
  • Queue: data added at one end, removed at other / Stack: data added and removed at same end (1)
  • Queue used for ordered processing / Stack used for reverse-order processing (e.g. recursion) (1)

  • Has a start pointer pointing to the first node (1)
  • Last node has a null pointer indicating end of list (1)

QUESTION 04
Write pseudocode to push an item onto a stack, including an appropriate check. [4]

MARK SCHEME

  • Check if stack is NOT full: IF TopPointer < MaxSize THEN (1)
  • Increment pointer: TopPointer ← TopPointer + 1 (1)
  • Store item: Stack[TopPointer] ← Item (1)
  • ENDIF / appropriate structure (1)

QUESTION 05
Explain two advantages and one disadvantage of using a linked list compared to an array. [3]

MARK SCHEME

  • [Adv] Easier to add/delete data — only pointers need to be changed, data does not need to be shifted (1)
  • [Adv] Dynamic size — can grow or shrink as needed without declaring fixed size in advance (1)
  • [Dis] Extra memory needed to store pointers alongside data / more complex to implement (1)

QUESTION 07
Write pseudocode to read all lines from a file called "records.txt" into a 1D array called Lines. [5]

MARK SCHEME

  • OPENFILE "records.txt" FOR READ (1)
  • DECLARE index : INTEGER / index ← 0 (1)
  • WHILE NOT EOF("records.txt") (1)
  • READFILE "records.txt", Lines[index] / index ← index + 1 (1)
  • ENDWHILE / CLOSEFILE "records.txt" (1)
★ CHALLENGE
QUESTION 08
Describe the steps to add a new node to a linked list. [4]

MARK SCHEME

  • Check there is an empty node available in the free list (1)
  • Assign data item to the first empty node in the free list (1)
  • Set pointer of new node to point to the node that should come after it (1)
  • Set pointer of previous node (that pointed to the position) to point to new node / update free list pointer (1)
