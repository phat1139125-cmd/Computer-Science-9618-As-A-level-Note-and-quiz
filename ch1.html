TOPIC 01 · §1.1
Data Representation
BCD · HEX · ASCII · UNICODE · CHARACTER SETS
CHARACTER SET

All of the characters that the computer can represent/use. Each character has a corresponding unique binary number.

FEATUREASCIIExtended ASCIIUNICODE
Bit length7-bit8-bit16-bit (UTF-16)
Characters128256100,000+
LanguagesEnglish onlyWestern EuropeanAll world languages
RelationshipBase standardASCII supersetASCII subset of Unicode
BCD — Binary Coded Decimal
Benefits of BCD
  • Easier to convert between BCD and denary
  • Less complex to encode/decode for programmers
  • Easier for digital equipment to display digits
  • Can represent monetary values exactly
Applications of BCD
  • Electronic displays — calculators, digital clocks
  • Only need to show individual digits
  • Storage of date/time in BIOS
  • Conversion with denary is simpler
Applications of Hex
  • MAC addresses
  • HTML colour codes
  • Memory addresses in assembly / machine code
  • Compact representation of binary
⚡ ASCII EXAM TIP  Each character has a unique code. Character replaced by its code. Codes stored in same order as in the word. Students will NOT be expected to memorise specific ASCII values.
TOPIC 02 · §1.2
Bitmap Graphics
PIXEL · FILE HEADER · RESOLUTION · BIT DEPTH · COLOUR DEPTH
BITMAP GRAPHIC

Made up of pixels, each of a single colour (with each colour having a unique binary value). Stored as a sequence of binary numbers — one binary value per pixel.

🔲 Pixel
  • The smallest addressable element in an image
  • Each pixel stores one colour value
📋 File Header
  • Stores metadata about the bitmap
  • Contains: file type, compression type, dimensions (W×H), file size, colour depth
📐 Image Resolution
  • Total number of pixels in image (W × H)
  • Higher resolution → sharper, less pixelated
  • More pixels → larger file size
🎨 Bit/Colour Depth
  • Number of bits used per pixel
  • Determines number of colours representable
  • More bits → greater colour range → larger file
File Size Calculation
FORMULA

File size (bits) = Image resolution (pixels) × Colour depth (bits per pixel)
Or: Width × Height × Bits per pixel
Divide by 8 for bytes, 1024 for KB, 1024² for MB

CHANGEEFFECT ON QUALITYEFFECT ON FILE SIZE
Increase resolutionSharper, more detail, less pixelationIncreases (more pixels to store)
Increase bit depthMore colours, closer to original imageIncreases (more bits per pixel)
✅ Bitmap Advantages
  • Widely supported
  • Accurate colour representation
  • Good for complex images (photos)
  • Can be compressed significantly
❌ Bitmap Disadvantages
  • Prone to pixelation when enlarged
  • Large file size
  • Harder to edit (each pixel individually)
⚡ EXAM FORMULA  File size = Width × Height × Colour depth. E.g. 100×100 pixels, 24-bit colour = 100×100×24 = 240,000 bits = 30,000 bytes = ~29.3 KB.
TOPIC 03 · §1.2
Vector Graphics
DRAWING OBJECTS · PROPERTIES · DRAWING LIST
VECTOR GRAPHIC

Stores a set of instructions about how to draw shapes. Does NOT store individual pixel values — stores coordinates and mathematical formulae for each object.

Drawing Object
  • Component of vector graphic
  • Created using a formula/command
  • e.g. circle, rectangle, line
Drawing Property
  • Contains data about the shapes
  • Defines appearance of a drawing object
  • e.g. colour, stroke width, fill
Drawing List
  • List of all drawing objects in image
  • Stores commands to draw each object
  • Contains object attributes
FEATUREVECTORBITMAP
StorageInstructions/formulaeBinary value per pixel
ScalingDoes NOT pixelate when enlargedPixelates when enlarged
File sizeSmaller — just instructionsLarger — data per pixel
EditingIndividual objects editableMust edit pixel by pixel
CompressionDoes NOT compress wellCan be compressed significantly
Best forLogos, diagrams, textPhotos, complex images
⚡ EXAM JUSTIFY  "Justify use of vector/bitmap for task": Vector → logo/diagram (scalable, small file, editable objects). Bitmap → photograph (accurate colours, widely supported).
TOPIC 04 · §1.2
Sound Representation
SAMPLING · SAMPLING RATE · SAMPLING RESOLUTION · ANALOGUE vs DIGITAL
HOW SOUND IS REPRESENTED

Amplitude is recorded a set number of times per second → each amplitude given a unique binary value → binary numbers saved in sequence.

Sampling
  • Taking measurements at regular intervals
  • Stores the amplitude value at each point
Sampling Rate
  • Number of samples taken per second (Hz)
  • e.g. CD quality = 44,100 Hz
Sampling Resolution
  • Number of bits used to store each sample
  • Also called bit depth
Analogue Data
  • A variable/continuously changing value
  • Sound waves are analogue
CHANGEEFFECT ON QUALITYEFFECT ON FILE SIZE
Increase sampling rateMore accurate — closer to original waveform. Reduces quantisation errors. Smaller gaps between samples.Increases (more samples stored)
Increase sampling resolutionWider range of amplitudes. Smaller quantisation errors. More accurate representation.Increases (more bits per sample)
FILE SIZE FORMULA

File size (bits) = Sampling rate × Sampling resolution × Duration (seconds) × Number of channels

⚡ QUANTISATION ERROR  Error introduced when the actual amplitude does not exactly match any stored value. Increasing sampling resolution reduces quantisation error because more amplitude values can be represented.
TOPIC 05 · §1.3
Compression
LOSSY · LOSSLESS · WHY COMPRESS
WHY COMPRESS?

Reduces file size → takes up less storage space. Faster download/upload. Less bandwidth used. Original may be too large to send as email attachment.

FEATURELOSSYLOSSLESS
Original dataLost/deleted — cannot be reconstructedPreserved — fully restored
File size reductionGreater reductionSmaller reduction
QualityReduced (acceptable loss)Identical to original
Use whenAll data not required / significant reduction neededAll data required / high quality needed
ExamplesJPEG images, MP3 audio, video streamingPNG images, ZIP files, text documents
Text files❌ Cannot use — would corrupt data✅ Must use for text
Compression Techniques by File Type
Images — Lossy
  • Reduce bit depth (fewer bits per pixel)
  • Reduce number of colours
  • Reduce resolution (fewer pixels)
Images — Lossless
  • Run-Length Encoding (RLE)
  • Replace sequences of same-colour pixels
Sound
  • Reduce amplitude range
  • Record only changes in sound
  • RLE for consecutive same sounds
⚡ EXAM: LOSSY ON TEXT FILE  "If lossy compression were used on a text file, it would corrupt the data because all data is required for it to make sense."
TOPIC 06 · §1.3
Run-Length Encoding (RLE)
LOSSLESS · HOW IT WORKS · LIMITATIONS
HOW RLE WORKS

Identifies groups/sequences of repeated characters and replaces them with a copy of the character plus the number of times it occurred.

  • e.g. AAAABBBCCCC → 4A 3B 4C (3 items instead of 11)
  • For images: stores colour code + number of identical consecutive pixels
✅ When RLE Works Well
  • Image has large areas of same colour
  • e.g. clipart, logos, simple graphics
  • Long sequences of identical data
❌ Limitations of RLE
  • Relies on sequences of repeated data
  • If no repeats: RGB → R1 B1 G1 (increases size!)
  • Photographs have many colour variations — RLE adds to file size
⚡ RLE LIMITATIONS EXAM  "RLE stores each colour and a count. If no sequences exist, it stores each pixel individually plus the count of 1 — only adding to total data and increasing file size."

QUESTION 02 · Calculate
A bitmap image is 400 pixels wide and 300 pixels high. The colour depth is 24 bits. Calculate the file size in kilobytes. [3]

MARK SCHEME

  • 400 × 300 = 120,000 pixels (1)
  • 120,000 × 24 = 2,880,000 bits (1)
  • 2,880,000 ÷ 8 ÷ 1024 = 351.6 KB (1)
Examiner: Show working — marks awarded for each correct step even if final answer is wrong.
● EASY
QUESTION 03 · Compare
State two differences between bitmap and vector graphics. [2]

MARK SCHEME (any 2)

  • Bitmap stores pixel values / vector stores mathematical instructions (1)
  • Bitmap pixelates when scaled / vector does not pixelate (1)
  • Bitmap has larger file size / vector has smaller file size (1)
  • Bitmap compresses well / vector does not compress well (1)
Examiner: Must give both sides for 1 mark each (contrast).
◆ STANDARD
QUESTION 04 · Explain
Explain two effects of increasing the sampling rate when recording sound. [4]

MARK SCHEME (any 2 × 2)

  • Sound is recorded more often / smaller gaps between samples (1) → digital waveform more closely resembles the analogue original (1)
  • Reduces quantisation errors (1) → improves accuracy of recorded sound (1)
  • Increases file size (1) → because more samples are stored (1)
Examiner: 4-mark explain = 2 effects, each with explanation of WHY. Effect alone = 1 mark, effect + reason = 2 marks.
◆ STANDARD
QUESTION 05 · Explain
Explain why lossy compression cannot be used on a text file. [2]

MARK SCHEME

  • Lossy compression permanently removes/deletes data (1)
  • Text files require all data to make sense / any missing data would corrupt the file (1)
Examiner: Must link "data is lost" to "text requires all data" — both points needed for 2 marks.
◆ STANDARD
QUESTION 06 · Compare
Compare lossy and lossless compression methods. [4]

MARK SCHEME (4 contrasting pairs)

  • Lossy permanently removes data / lossless preserves all original data (1)
  • Lossy achieves greater file size reduction / lossless achieves smaller reduction (1)
  • Lossy reduces quality / lossless maintains identical quality (1)
  • Lossy used when quality loss acceptable / lossless used when all data needed (1)
Examiner: Both sides for each contrast point.
★ CHALLENGE
QUESTION 07 · Explain
Explain two limitations of run-length encoding (RLE). [4]

MARK SCHEME

  • RLE relies on sequences of repeated data (1) — if few repeats exist, file size may actually increase (1)
  • For images with many colours (e.g. photos), each pixel may be a different colour (1) — RLE stores each pixel plus a count of 1, adding to the total data (1)
Examiner: Limitation alone = 1 mark. Limitation + explanation = 2 marks. Must explain WHY it is a limitation.
★ CHALLENGE
QUESTION 08 · Justify
A graphic designer needs to create a company logo that will be printed at many different sizes — from a business card to a billboard.
Justify whether a bitmap or vector graphic should be used for the logo. [3]

MARK SCHEME

  • Vector graphic should be used (1)
  • Vector graphics do not pixelate when scaled / can be enlarged without loss of quality (1)
  • The logo needs to be printed at many different sizes, so maintaining quality at all sizes is essential (1)
Examiner: Named choice + advantage + link to scenario = 3 marks. Just "vector is better" = 0.
