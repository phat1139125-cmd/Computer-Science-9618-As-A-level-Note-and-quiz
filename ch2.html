TOPIC 01
Purpose and Benefits of Networking
WHY DO WE BUILD NETWORKS?
DEFINITION

A network is two or more computers connected together to share data and resources.

Communication
  • Share data between devices
  • Send messages and emails
  • Video calls and collaboration
Resource Sharing
  • Share printers and scanners
  • Share software licences
  • Shared internet connection
Central Management
  • Centralised security policies
  • Centralised backups
  • User account management
Cost Efficiency
  • One printer for many users
  • Shared software licences
  • Single internet connection
⚡ EXAM TRIGGER  If asked "give two benefits of networking" — the safe answers are: (1) sharing of hardware/resources, (2) central management of security/backups. These are the most consistently awarded marks.

Geographical areaSmall — one building/siteLarge — cities, countries

Data transfer rateHigh — fastLow — slower

⚡ EXAM PATTERN  LAN vs WAN = give BOTH sides. Write: "LAN covers a small geographical area whereas WAN covers a large area." Never state just one side — you need the contrast for each mark.
TOPIC 03
Client-Server vs Peer-to-Peer
NETWORK ORGANISATION MODELS
FEATURE CLIENT-SERVER PEER-TO-PEER
StructureDedicated server + clientsAll computers equal status
ProcessingServer processes requestsEach computer processes own
SecurityCentrally managedEach device manages own
BackupsCentral backup on serverNo central backup
FilesStored centrally on serverDistributed across all devices

CLIENT-SERVER PROCESS

⚡ P2P EXAM SHORTCUT  Any P2P drawback = "no central management of [X]". X = security / backup / files. This phrase = 1 mark each time. The word "central" is the key marker.

FEATURE THICK CLIENT THIN CLIENT
Processing locationLocally on client deviceOn the server
Server roleMinimal processingAll processing
Local resourcesSoftware installed locallyMinimal — just display

TOPIC 05
Network Topologies
BUS · STAR · MESH · HYBRID

🚌 BUS TOPOLOGY

  • ✅ Simple, cheap, less cabling
  • ❌ Backbone fails → whole network down
  • ❌ More collisions — all share one channel
  • Data broadcast to ALL devices

⭐ STAR TOPOLOGY

  • ✅ Fewer collisions — dedicated links
  • ✅ Scalable — add device to switch
  • ✅ One cable fails → only that device affected
  • ❌ Switch failure = whole network fails

🕸️ MESH TOPOLOGY

  • ✅ Alternate routes if link fails
  • ✅ High resilience, no single point of failure
  • ❌ Expensive — lots of cabling
  • ❌ Complex to manage

🔗 HYBRID TOPOLOGY

  • ✅ Flexible — tailored to needs
  • ✅ Inherits best of each topology
  • ❌ Complex and expensive
  • Large organisations with varied needs
TOPOLOGY PACKET TRAVEL USE WHEN
BUSBroadcast to ALL — each checks addressSmall cheap network
STARSwitch reads MAC → sends to target ONLYOffice/school needing performance
MESHNodes relay via best available pathCritical systems, ISP backbones
HYBRIDDepends on sub-topology usedLarge org with varied departments
⚡ EXAM PATTERN  "Justify topology for situation": state advantage + link to context. E.g. "Star topology should be used because each device has a dedicated link to the switch, reducing collisions, which is important as many students use the network simultaneously."
TOPIC 06
Cloud Computing
PUBLIC CLOUD · PRIVATE CLOUD · BENEFITS · DRAWBACKS
DEFINITION

Accessing files, applications, or services stored on remote servers via the internet, rather than on local hardware.

FEATURE PUBLIC CLOUD PRIVATE CLOUD
ProviderThird-party (Google, AWS)Organisation's own infrastructure
AccessAvailable to anyone on internetRestricted to authorised users only
ExamplesGoogle Drive, DropboxInternal company server
CostPay-as-you-go / free tierHigh upfront investment
ControlLimited — provider controlsFull control over data
✅ Advantages
  • Access from any device with internet
  • Saves local storage space
  • Automatic backups (usually)
  • Scalable — increase storage easily
  • Easy file sharing
  • No upfront hardware cost
❌ Disadvantages
  • Requires internet connection
  • Dependent on third-party provider
  • Server downtime = no access
  • Recurring costs (long-term)
  • Data privacy and security concerns
  • Slow to upload/download large files
TOPIC 07
Transmission Media
WIRED vs WIRELESS · COPPER · FIBRE · WiFi · RADIO · MICROWAVE · SATELLITE
MEDIA SIGNAL ADVANTAGES DISADVANTAGES
Copper Cable Electrical Cheap · Flexible · Easy to install Interference (EMI) · Slower · Needs repeaters · Easier to tap
Fibre Optic Light pulses Very high bandwidth · Low interference · Long distances · Hard to intercept Fragile · Expensive · Difficult to install/terminate
WiFi / Radio EM waves No cables · Portable · Easy expansion Interference · Walls reduce signal · Security risk · Higher latency
Microwave EM waves (high freq) Long distances · No cables between towers Line of sight required · Weather affected
Satellite EM waves (orbit) Global coverage · Remote areas Very high latency · Expensive · Weather affected
⚡ FIBRE vs COPPER KEY  Always explain WHY: "Fibre optic uses light pulses so it is not affected by electromagnetic interference, whereas copper uses electrical signals which can be disrupted by EMI." The explanation = the mark, not just naming the medium.
TOPIC 08
LAN Hardware
SWITCH · SERVER · NIC · WNIC · WAP · BRIDGE · REPEATER · CABLES
🔀 Switch
  • Connects devices within LAN
  • Reads destination MAC address
  • Forwards to target device ONLY
  • Reduces collisions vs hub
🗄️ Server
  • Manages centralised resources
  • File/print/web server types
  • Processes client requests
  • Returns results to clients
🃏 NIC (Wired)
  • Connects device to wired LAN
  • Digital ↔ electrical signal
  • Contains unique MAC address
  • Implements Ethernet protocol
📡 WNIC (Wireless)
  • Connects device to wireless LAN
  • Digital ↔ analogue radio waves
  • Encrypts and decrypts data
  • Provides MAC address
🔁 WAP
  • Wireless to wired LAN bridge
  • Transmits/receives radio signals
  • Extends wireless coverage
  • NOT a router — no IP routing
🌉 Bridge
  • Connects two LANs — SAME protocol
  • Filters traffic between networks
  • Reduces traffic in each LAN
🔄 Repeater
  • REGENERATES degraded signal
  • Extends cable range
  • Digital signal only — regenerate ≠ amplify
🔌 Cables
  • Copper: electrical, cheaper, flexible
  • Fibre: light, faster, less interference
  • Connect devices to switch/router
⚡ WNIC EXAM TRICK  TWO functions of WNIC = always: (1) converts digital to analogue radio waves for transmission, (2) provides MAC address. Bonus: (3) encrypts/decrypts data. These three are the most consistently marked.
TOPIC 09
Router Role
★ MOST EXAMINED DEVICE
DEFINITION

A device that routes and forwards data packets between different networks using IP addresses.

Router Functions (exam list)
  • Receives packets from devices/internet
  • Stores IP & MAC addresses of connected devices
  • Maintains a ROUTING TABLE
  • Routes packets to destination via IP
  • Finds most efficient path to destination
  • Assigns private IP addresses (DHCP)
  • Can act as firewall / gateway
  • Performs protocol conversion
Routing Table
  • Database stored in router
  • Maps destination IP → next hop
  • Updated dynamically as network changes
  • Used to find most efficient path
⚡ EXAM CRITICAL  Router = "routing table" + "IP address" + "most efficient path" + "assigns private IP". Never say router "connects devices in LAN" — that is the SWITCH. Router connects NETWORKS together.
TOPIC 10
Ethernet and CSMA/CD
HOW COLLISIONS ARE DETECTED AND AVOIDED
ETHERNET

A wired LAN protocol — data transmitted in frames. Each frame contains: source MAC, destination MAC, data, error-check (CRC).

CSMA/CD PROCESS — IN ORDER

Device listens to channel — checks if line is idle (carrier sense)

If channel is free/idle → device transmits data

If two devices transmit simultaneously → COLLISION detected

All nodes send a JAM signal — all stop transmitting immediately

Each device waits a random backoff time before retransmitting

⚡ 4-5 MARK QUESTION PATTERN  Must include all 5 steps in order. Critical marks: "listens first", "only sends when idle", "collision detected", "JAM signal", "random wait". The RANDOM wait = 1 mark students miss. Explain WHY random: "if both waited the same time, they would collide again."
TOPIC 11
Bit Streaming
REAL-TIME · ON-DEMAND · EFFECT OF BIT RATE
FEATURE REAL-TIME ON-DEMAND
When recordedLive — as it happensPre-recorded, uploaded to server
Pause/rewind❌ Cannot pause or rewind✅ Can pause, rewind, fast-forward
DeliverySent to buffer as recordedStored on server, streamed on request
ExamplesLive news, live sports, live gamingNetflix, YouTube, iPlayer
HOW STREAMING WORKS

Video is compressed → Server sends data to a buffer on client → Client plays from buffer continuously → Buffer absorbs variation in network speed

⚡ Bit Rate Impact
  • Higher bit rate = better video/audio quality
  • Higher bit rate = more data per second needed
  • Low broadband + high bit rate → buffering
  • Services adapt bit rate to connection speed
⚡ EXAM KEY  Buffer = always 1 mark. "Data sent to buffer on client device; client plays from buffer." Real-time vs on-demand: "cannot be paused" (real-time) vs "can be paused/rewound" (on-demand) = clearest exam distinction.

FEATURE WWW (World Wide Web) INTERNET
What it isCollection of web pages/resourcesGlobal network of networks
ProtocolHTTP / HTTPSTCP / IP

TOPIC 13
Internet Hardware
MODEM · PSTN · DEDICATED LINES · CELLULAR NETWORKS
📟 Modem
  • MOdulator/DEModulator
  • Digital → analogue (to send via PSTN)
  • Analogue → digital (to receive)
  • Needed when only phone line available
☎️ PSTN
  • Public Switched Telephone Network
  • Traditional circuit-switched network
  • Full duplex transmission
  • Dedicated channel during call
  • Line active even in power cut
📡 Dedicated Lines
  • Permanent, always-on connection
  • Reserved for one organisation
  • Guaranteed bandwidth — not shared
  • Symmetrical upload/download
  • More expensive than broadband
📱 Cellular Networks
  • Area divided into cells (base stations)
  • Device connects to nearest tower
  • Handoff as device moves
  • 3G / 4G / 5G standards
  • Internet in remote areas
⚡ MODEM EXAM ANSWER  "Converts digital data to analogue signals for transmission over telephone lines, and converts received analogue signals back to digital." Must state BOTH directions for full marks.

TOPIC 16
DNS Role
HOW A URL BECOMES AN IP ADDRESS
PURPOSE

DNS (Domain Name System) translates human-readable domain names into machine-readable IP addresses.

User types URL
→
Browser parses domain
→
Sent to DNS server
→
DNS searches database
→
IP returned
→
Browser connects to server

User enters URL into web browser

Browser parses the URL to extract the domain name

Domain name sent to DNS server

DNS searches its database for matching IP address

If found: IP address returned to browser → page loads

If NOT found: request forwarded to higher-level DNS

Higher DNS returns IP; lower DNS caches result for future lookups

⚡ 4-MARK DNS QUESTION  Key steps: "parses URL" → "sent to DNS" → "searches database" → "returns IP" → "forwarded to higher DNS if not found" → "lower DNS caches result." Step 7 (CACHING) is the mark most students miss.

● EASY
QUESTION 01 · Definition
Define the term "LAN" (Local Area Network). [2]

MARK SCHEME

  • A network that covers a small geographical area (1)
  • Infrastructure is privately owned / not controlled by external organisations (1)
Examiner: "Small geographical area" alone is 1 mark. The private ownership point is the second mark many students miss. "High speed" alone does NOT score — it must be contrasted with WAN in a compare question.
● EASY
QUESTION 02 · Definition
State two functions of a WNIC. [2]

MARK SCHEME (any two)

  • Converts digital data to analogue radio waves for transmission (1)
  • Converts received analogue radio waves back to digital data (1)
  • Provides the device's MAC address on the network (1)
  • Encrypts and decrypts data (1)
Examiner: The signal conversion answers are the safest marks. "Allows wireless connection" alone is NOT enough — you must describe what it does technically.
● EASY
QUESTION 03 · Describe
Describe the purpose of a router in a network. [3]

MARK SCHEME (any three)

  • Routes/forwards data packets between different networks (1)
  • Uses IP addresses to determine the destination of packets (1)
  • Maintains a routing table to find the most efficient path (1)
  • Assigns private IP addresses to devices on a LAN (1)
Examiner: "Routing table" + "IP address" + "most efficient path" = 3 easy marks. Don't say "connects devices in a LAN" — that's the switch.
◆ STANDARD
QUESTION 04 · Compare
Compare a star topology with a bus topology. [4]

MARK SCHEME (4 contrasting points)

  • Star uses a central switch whereas bus uses a single backbone cable (1)
  • Star has fewer collisions because each device has a dedicated link / bus has more collisions as all devices share the same channel (1)
  • In star, one cable failing only affects that device / in bus, backbone failure causes whole network to fail (1)
  • Star is more expensive due to central switch and more cabling / bus is cheaper and uses less cable (1)
Examiner: Each point must give BOTH sides. "Star has fewer collisions" alone = 0 marks. "Star has fewer collisions because... whereas bus has more collisions because..." = 1 mark.
◆ STANDARD
QUESTION 05 · Process
Describe the CSMA/CD process used in Ethernet networks. [4]

MARK SCHEME

  • Device listens to the channel to check if it is free/idle (1)
  • If channel is free, the device transmits data (1)
  • If two devices transmit simultaneously, a collision is detected (1)
  • A JAM signal is sent by all nodes — all stop transmitting (1)
  • Each device waits a random backoff time before attempting to retransmit (1)
Examiner: 5 steps available for 4 marks — full credit from any 4. The RANDOM wait step is the most missed. Explain why random: "prevents both devices retransmitting at the same time again."
◆ STANDARD
QUESTION 06 · Explain
Explain the role of DNS when a user enters a URL in a web browser. [4]

MARK SCHEME

  • Browser parses the URL to extract the domain name (1)
  • Domain name is sent to a DNS server (1)
  • DNS searches its database for the corresponding IP address (1)
  • If found, IP address is returned to the browser (1)
  • If not found, request is forwarded to a higher-level DNS server (1)
  • Lower-level DNS caches / stores the result for future requests (1)
Examiner: For 4 marks, steps 1–5 cover the core process. Step 6 (caching) is a bonus mark. Don't forget "parses URL" as step 1 — many students jump straight to DNS.
◆ STANDARD
QUESTION 07 · Compare
Compare IPv4 and IPv6 addressing. [4]

MARK SCHEME (any 4 contrasting pairs)

  • IPv4 is 32-bit whereas IPv6 is 128-bit (1)
  • IPv4 has 4 groups / IPv6 has 8 groups (1)
  • IPv4 written in denary / IPv6 written in hexadecimal (1)
  • IPv4 groups separated by dots / IPv6 groups separated by colons (1)
  • IPv6 allows groups of zeros to be replaced with :: / IPv4 has no such shorthand (1)
Examiner: Contrasting pairs = marks. "IPv4 is 32-bit" alone = 0 in a compare question. "IPv4 is 32-bit whereas IPv6 is 128-bit" = 1 mark.
◆ STANDARD
QUESTION 08 · Advantages/Disadvantages
State two advantages and two disadvantages of using a private cloud. [4]

MARK SCHEME

  • [Advantage] Full control over data and security (1)
  • [Advantage] Not dependent on internet — accessible via internal network (1)
  • [Advantage] No third-party access to sensitive data (1)
  • [Disadvantage] High upfront cost to set up infrastructure (1)
  • [Disadvantage] Requires IT staff to maintain (1)
  • [Disadvantage] Less scalable than public cloud (1)
Examiner: Accept any valid advantage/disadvantage. "More secure" alone = 1 mark but "more secure because data is not stored by a third party" = stronger answer.
◆ STANDARD
QUESTION 09 · Describe
Describe how data is transmitted between two devices connected in a star topology. [3]

MARK SCHEME

  • Sending device transmits a data frame to the central switch (1)
  • Switch reads the destination MAC address in the frame (1)
  • Switch forwards the frame only to the device with that MAC address (1)
Examiner: Key marks: "MAC address" + "switch reads" + "forwards only to destination." The word "only" is important — switch does NOT broadcast like a hub.
★ CHALLENGE
QUESTION 10 · Scenario
A hospital is designing a new network. Patient records must be kept secure and always accessible. The network serves 500 staff in a large building with multiple departments.
Justify which network topology would be most suitable for the hospital network. [4]

MARK SCHEME (star or mesh both acceptable with justification)

  • [Star] Central switch means each device has a dedicated link, reducing collisions which is important with 500 users (1)
  • [Star] Easy to add new devices to the switch as the hospital expands (1)
  • [Mesh] If one link fails, alternate routes exist, ensuring patient records remain accessible at all times (1)
  • [Mesh] No single point of failure which is critical in a hospital environment (1)
  • Hybrid could combine benefits of both for different departments (1)
Examiner: Full marks require: name topology + advantage + link to scenario context. "Star is suitable because it has fewer collisions" = 1 mark. "Star is suitable because each device has a dedicated link reducing collisions, which is important as 500 staff use the network simultaneously" = 2 marks (advantage + context).
★ CHALLENGE
QUESTION 11 · Scenario
A school is deciding between a thin client and thick client setup for 200 student workstations.
Discuss the suitability of thin client and thick client architectures for the school. [6]

MARK SCHEME (3 marks each side, max 6)

  • [Thin] Software updates applied once on server — easier and cheaper to maintain 200 devices (1)
  • [Thin] Cheaper hardware required for each workstation — lower cost for school (1)
  • [Thin] Security managed centrally on server — staff can control all devices easily (1)
  • [Thick] If server fails, students can still work locally — less disruption (1)
  • [Thick] Better local performance for tasks like graphic design or video editing (1)
  • [Thick] Higher hardware cost and maintenance burden across 200 devices (negative) (1)
Examiner: Discuss = both sides with context. Link each point to school. "Thin client is suitable because updates only need to be applied to the server, reducing the time and cost of maintaining 200 student machines."
★ CHALLENGE
QUESTION 12 · Explain
Explain four benefits of subnetting a large organisational network. [4]

MARK SCHEME — S·E·T·M

  • [Security] Data stays within its subnet so devices do not receive unintended data from other subnets (1)
  • [Expansion] Allows a greater range of IP addresses, making it easier to extend the network (1)
  • [Traffic] Data remains within the subnet, reducing traffic on the wider network and improving speed (1)
  • [Management] Faults can be isolated to a single subnet without affecting the rest of the network (1)
Examiner: Use the word "subnet" in each answer. One mark each. "Improves security" alone = 0. "Data stays within the subnet so devices do not receive unintended data" = 1 mark.
★ CHALLENGE
QUESTION 13 · Compare
Compare real-time bit streaming and on-demand bit streaming. [4]

MARK SCHEME (any 4 contrasting pairs)

  • Real-time streams a live event as it happens / on-demand streams pre-recorded content uploaded to a server (1)
  • Real-time cannot be paused or rewound / on-demand can be paused, rewound and fast-forwarded (1)
  • Real-time data sent to buffer as it is recorded / on-demand data stored on server then streamed on request (1)
  • Real-time requires consistent connection (no stored copy) / on-demand buffers more data ahead (1)
Examiner: "Cannot be paused" (real-time) vs "can be paused" (on-demand) = clearest and safest contrast pair. Always contrast — one-sided answers score 0 in compare questions.
★ CHALLENGE
QUESTION 14 · Explain
Explain the difference between a public IP address and a private IP address, and state one security implication of each. [4]

MARK SCHEME

  • Public IP is visible to any device on the internet, assigned by ISP, globally unique (1)
  • Private IP is only visible within the LAN, assigned by the router, only unique within the LAN (1)
  • [Security — Public] Can be targeted by external attackers as it is visible on the internet (1)
  • [Security — Private] Cannot be accessed directly from the internet, providing protection from external threats (1)
Examiner: Security implication must be specific to IP type. "Public IP can be attacked from internet because it is visible globally" = mark. "Private IP is safer" alone = 0.
